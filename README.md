# Terminal systems engineering work samples

Two case studies show the design, debugging, and validation of deterministic terminal tasks. They describe the engineering work without publishing protected reference solutions, hidden fixtures, grader internals, or answer files from benchmark packages.

- [Conservative flood replay](flood-replay.md): numerical simulation, conservation, and transport-history auditing.
- [Elastic training recovery](elastic-training-recovery.md): checkpoint evidence reconstruction and deterministic distributed-training continuation.

For a fully public, runnable code sample, see the [bulk certificate generator API](https://github.com/Teja2000-byte/bulk-certificate-generator-api), a FastAPI service with asynchronous jobs, SQLite persistence, partial-failure handling, PDF/ZIP generation, Docker setup, and tests.

These summaries are not claims that every platform review or model-calibration gate passed. Reproducible local controls and any platform outcome are distinguished in each case study.
